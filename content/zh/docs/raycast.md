# Raycast

Raycast 是一款启动器和效率工具。本页列出几个常用扩展。

## 使用 {#usage}

Raycast 的功能可以通过 Raycast Store 里的扩展增加。

### 安装扩展 {#install-extensions}

从 Raycast Store 安装以下扩展：

- [MyIP](https://www.raycast.com/Kang/myip)：查看本机 IP 地址。
- [Brew](https://www.raycast.com/nhojb/brew)：搜索和安装 Homebrew 软件包。
- [Kill Process](https://www.raycast.com/rolandleth/kill-process)：快速终止进程。
